CYBERGUARD - CYBER SECURITY AWARENESS SYSTEM
==============================================

Technology
----------
Python + Flask + SQLite + HTML + CSS

Project Structure
-----------------
CyberSecurityAwarenessSystem/
│
├── app.py
├── database.db
├── requirements.txt
├── README.txt
│
├── templates/
│   ├── base.html
│   ├── index.html
│   ├── login.html
│   ├── register.html
│   ├── url_checker.html
│   ├── email_analysis.html
│   ├── quiz.html
│   ├── awareness.html
│   └── dashboard.html
│
└── static/
    └── style.css

Features
--------
1. Attractive Cyber Security home page
2. Login and registration
3. URL phishing warning checker
4. Email phishing analyzer
5. Cyber security MCQ quiz
6. Awareness tips
7. User dashboard
8. SQLite database

HOW TO RUN
----------
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open VS Code Terminal.
4. Run:
       pip install -r requirements.txt
5. Run:
       python app.py
6. Open in browser:
       http://127.0.0.1:5000

IMPORTANT
---------
The project is educational and uses simple rule-based checks.
It does not guarantee that a website or email is safe.
